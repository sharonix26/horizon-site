# Horizon Global Trade — Website

A responsive B2B landing page for an international beverage trading company, built with **HTML**, **CSS**, and **vanilla JavaScript** — featuring a **custom-coded 3D carousel** and fully bespoke design.  
Hosted on **Firebase** for fast global delivery.


## ✨ Features
- **Custom 3D Carousel** — smooth, interactive product showcase built from scratch in vanilla JS.
- **Bespoke Visual Design** — modern layout, tailored typography, and branding from concept to code.
- **Responsive UI** — optimized for mobile, tablet, and desktop.
- **Firebase Hosting** — secure, CDN-backed delivery with scalable deployment.
- **Privacy & 404 Pages** — fully styled to match brand identity.

## 🛠️ Stack
- HTML
- CSS (custom styling, animations)
- Vanilla JavaScript (DOM manipulation, carousel logic)
- Firebase Hosting
